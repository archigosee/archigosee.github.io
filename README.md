# Kaleab Mekonnen — Portfolio

Personal portfolio: full-stack development and AI automation.

- **3D**: React Three Fiber + drei: a "living system" of nodes with cursor physics and data pulses
- **Motion**: GSAP ScrollTrigger + Lenis: the core explodes into Frontend / API / Data layers on scroll
- **Projects**: shader-driven covers (liquid distortion, chromatic aberration, tilt) rendered in a single WebGL context via drei `View`

```bash
npm install
npm run dev
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
Project content lives in `src/data.ts`.
